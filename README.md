# Best Model

A Codex skill that assesses a task or prompt and recommends the best available model and reasoning effort.

## Install

Clone or copy this repository into your Codex skills directory as `best-model`:

```text
$CODEX_HOME/skills/best-model
```

Then invoke it with `$best-model` or `/best-model`.

## Files

- `SKILL.md` defines the evaluation workflow and response format.
- `agents/openai.yaml` supplies the Codex UI metadata.
